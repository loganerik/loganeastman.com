TRYHARD editor

Writing guide

Everything you can use in a column or the About page. Expand a section for instructions; copy an example and paste it into the Body editor’s Markdown mode.

Editor basics
Rich Text
Write normally and use the formatting toolbar. Select a passage before applying bold, emphasis, or a link. Use the + insert menu for images, code blocks, and the four TRYHARD blocks below.
Markdown
Edit the source directly. The examples in this guide belong in this mode; switching back to Rich Text lets you continue editing. Put each special block on its own lines, with a blank line before and after.
Headings
The Title field supplies the main heading. Start sections with Heading 2 (##), then use Heading 3 (###) for subsections.
Paragraphs
Use a blank line between paragraphs in Markdown. The site controls font sizes, reading width, frames, and ornaments.
Block previews
Custom blocks have simplified previews inside the editor. The published page supplies their complete styling.
TRYHARD’s four special blocks

Pull quote

+ → Pull quote. Sets a short line apart in the green-and-rose quotation panel. The design adds the opening quotation mark. Use the toolbar’s ordinary Quote tool for a passage quoted within the argument.

Markdown example
{{< pullquote >}}
A line worth setting apart.
{{< /pullquote >}}

Aside / digression

+ → Aside (digression). A separate note for a qualification, digression, or source detail. Its optional Label defaults to “A small digression”. The Text field accepts Markdown links, emphasis, and paragraphs.

Markdown example
{{< aside label="A note on sources" >}}
Some useful context, with a [source](https://example.com).

A second paragraph, if needed.
{{< /aside >}}

For the default label, start with {{< aside >}} instead.

Sunburst divider

+ → Sunburst divider. Inserts the gold sunburst on a green rule between passages, the same mark that sits above every ## section heading and closes each column. There are no fields to fill in. Continue in a new paragraph below it.

Markdown example
{{< ornament >}}

Figure (image)

+ → Figure (image). Adds an image within the writing. Choose an Image, describe it in Alt text, and optionally add a Caption. Gold frame is on by default; switch it off for a plain image. Duotone applies the green-toned treatment, with or without the frame.

Markdown example
{{< figure src="photo.jpg" alt="A description of the photograph" caption="Photo credit or context" duotone="true" >}}

{{< figure src="photo.jpg" alt="A description" frame="false" duotone="true" >}}

Upload your actual image first and replace photo.jpg with its filename. Omit duotone="true" for original colors; add frame="false" for a plain, unframed image. Caption is optional; the Figure is separate from the entry’s Cover image.

Code block

Use + → Code block, or paste a fenced block in Markdown. A language after the opening fence enables syntax highlighting.

Markdown example
```javascript
const idea = "Start here";
```

Table

Use Markdown mode for a table. The second line separates its headings from the rows.

Markdown example
| Idea | Observation |
| --- | --- |
| First idea | What you noticed |
| Second idea | More detail |

Footnote

Add the reference where the note belongs, then put its definition at the end of the body. Each note needs its own matching label. Use Markdown mode to keep the source easy to edit.

Markdown example
A thought with a source.[^source]

[^source]: The source or a longer explanation, with a [link](https://example.com).
Images, captions, and uploads

Upload a JPG, PNG, or WebP through the image picker for the entry you are editing. Its files live beside its Markdown file so the site can resize them. Keep the filename provided by the picker when inserting the image.

Image
The standard + menu Image tool. Ordinary Markdown images automatically receive the site’s gold frame. An optional image title becomes the visible caption.
Figure
The + menu Figure tool adds Caption, Gold frame, and Duotone controls.
Cover → Image
A featured photo above a column and on its homepage lead. It does not insert an image into the Body.
Alt text
Describe what the image communicates for readers who cannot see it. A useful description is better than a filename or “image of”.
Caption
Visible context or credit below the picture. The Figure and Cover captions accept Markdown links and emphasis.
Duotone
Applies the site’s green-toned treatment where the Figure or featured image is rendered on the column page. Leave off to keep the photo’s original colors.
Standard image with a caption
![A description of the photograph](photo.jpg "A visible caption or photo credit")

The filename above is an example: replace it with a file you actually uploaded. Avoid renaming a file after it has been inserted without also updating its references.

Title, date, topics, cover, and About fields

The fields above Body fill in the Markdown file’s metadata for you. Keep that metadata out of Body.

Title
The main headline, already displayed in the masthead. Body headings begin at Heading 2.
Date
Controls archive order and the weekly lineup. The picker uses your device’s local time; the public site displays dates in Los Angeles time.
Description
An optional plain-text standfirst and description for search and link previews. If a column’s Description is blank, the homepage draws an excerpt from its first prose paragraph.
Categories
Broad subjects such as Culture or Technology. Separate names with commas, for example Culture, Technology, and reuse names consistently.
Tags
Specific recurring ideas such as attention or Los Angeles. Separate names with commas, for example attention, Los Angeles. Matching tags connect columns in Explore.
Cover → Pattern
lines: vertical stripes; waves: flowing curves; steps: stepped buildings; rays: sun rays; arches: repeating arches; scallops: overlapping semicircles. Leave blank for an automatic choice.
Cover → Accent
Choose sage, rose, jade, brown, or olive. Leave blank for an automatic palette. Generated artwork remains available for the archive cards even when the entry has a featured photo.
About → Portrait
Your original photo above the About text. Upload it through Portrait and describe it in Portrait alt text. Portrait Deco frame is a separate transparent overlay; keep the existing frame to retain the rose and arch, or clear it for a plain photo.
About → Body
The same formatting, special blocks, figures, and footnotes work here. Its Title and optional Description are separate fields.
Drafts, saving, previewing, and publishing
  1. Save stores the column as an unpublished draft on its own branch. Nothing reaches the public site until you publish.
  2. The Workflow board (top bar) shows every unpublished column in three lanes: Drafts, In review, Ready. Drag a card or use the status menu in the editor to move it.
  3. While writing, the preview pane beside the form shows the column in the site's type and layout. It is an approximation; blocks look simplified there.
  4. For the real thing, use Preview build ↗ (bottom corner). A minute or two after each save, it opens a private copy of the whole site with this column included, at a pages.dev address. Share that link with a reader if you like; it is not indexed.
  5. Publish (editor top bar, or the Ready lane) merges the column into the site. The public site updates after its build finishes, about a minute.
  6. The Draft switch is a second safety: leave it on and the column stays out of the public site even after publishing. Switch it off before you publish.
  7. A future Date keeps the column out of the public site until that date and the next site build; it does not schedule a build by itself.
