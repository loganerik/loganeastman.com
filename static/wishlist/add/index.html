Set up iPhone sharing
  1. In Shortcuts, create a shortcut named Add to Logan’s List. In its Details, turn on Show in Share Sheet and set the accepted input to URLs.
  2. Add the URL action. Enter https://loganeastman.com/wishlist/add/# and insert the Shortcut Input variable immediately after the #.
  3. Add the Open URLs action and save. In Safari, share a shop or product page and choose your shortcut.
